# Home Labs

The hands-on half of the homework. While the **paper** homework track builds
test-question skills (reading a chromatogram, working the soil triangle, writing
an analysis paragraph), the **home-lab** track builds bench skill — actually
running the tests, fast and in the right order, the way the kids will have to at
competition.

## Contents

- [`Home_Lab_Safety_Agreement.md`](Home_Lab_Safety_Agreement.md) — one-time parent
  signature, required before any home lab is assigned. Also lists exactly what is
  in the kit and what the family supplies.
- `Kit_Assembly_Guide.md` — shopping list and prep steps for the coach: what to
  buy, how to portion the powder bags, how to make the red-cabbage indicator, and
  how to build the numbered "unknown" sets.
- `Lab_Card_XX_*.md` — the individual home-lab assignments, one per relevant
  session. Each is a single page a student can work from with a parent: the goal,
  the materials, numbered steps, a results table to fill in, and 2–3 follow-up
  questions. Answer notes for the coach are at the bottom of each card.

## The rule that never changes

Food-grade powders, mild household iodine, cabbage-water indicator, vinegar,
water, a magnet. **No strong acids or bases, no heat, no flames at home.** The
HCl test and all burn tests are practice-only, with the coach. See the safety
agreement.
