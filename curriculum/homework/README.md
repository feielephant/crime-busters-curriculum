# Homework

Homework_01 … Homework_12 are one take-home set per teaching session.
**Homework_13 and Homework_14** are "general knowledge" sweeps not tied to a
single session — they cover the loose short-answer items that fill the
"general knowledge / junior detective" section of real invitational tests (flame
tests, PCR stages, the blood-spatter information list, minutiae identification,
powder uses, natural polymers, empirical formulas, and the harder stretch
chemistry from the toughest reference tests). Assign 13 mid-season and 14 in the
last few weeks. See [`../Test_Coverage_Map.md`](../Test_Coverage_Map.md) for the
full topic-by-topic audit of what's covered where.

Each of Homework_01 … Homework_12 has two tracks:

- **Paper track** — written practice at real invitational difficulty: identify
  substances from a description of their test results, work the soil texture
  triangle, calculate an Rf or a spatter angle, read a gel, write an analysis
  paragraph against a scoring rubric. Original scenarios and numbers, built in the
  format real tests use. Answer key included.
- **Home-lab track** — a hands-on assignment from
  [`../home_labs/`](../home_labs/), done with a parent using the home practice
  kit. Not every session has one (some topics — blood typing, glass fracture —
  can't be done safely or practically at home); those sessions have a
  paper-only homework and the hands-on practice happens at the next meeting.

Assign the paper track to everyone. Assign the home-lab track only to students
whose parent has signed the
[Home Lab Safety Agreement](../home_labs/Home_Lab_Safety_Agreement.md).
