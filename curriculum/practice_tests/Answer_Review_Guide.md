# Answer Review Guide

The review is where a practice test turns into learning. Budget ~40 minutes right
after the test, while it's fresh.

## Step 1 — Score it together (10 min)

Go through the key section by section with the team. For each item, mark it and —
this is the important part — sort every **miss** into one of three buckets:

| Bucket | Meaning | What to do about it |
|---|---|---|
| **Didn't know it** | The content wasn't learned or wasn't remembered. | Goes on the review list. Add it to a note sheet. Re-teach if several kids missed it. |
| **Knew it, ran out of time** | Right idea, but blank or rushed because the clock beat them. | A *pacing* problem, not a knowledge problem. Work on station division and time budgeting. |
| **Test-reading error** | Knew the content, answered the wrong thing — missed a sub-part, ignored "show your work," misread the table. | A *habit* problem. Drill reading the whole question and every "(_ pts)" tag. |

Write the three-bucket tally on the board. The mix tells you where the next few
weeks go: mostly "didn't know it" → more teaching; mostly "ran out of time" →
more timed drills; mostly "reading errors" → slow down and annotate.

## Step 2 — The analysis section (10 min)

Score the written analysis against `Analysis_Report_Rubric.md`. Then rewrite one
paragraph together on the board to model the structure — culprit, motive,
evidence-with-reasons, clear-the-others. Almost every team leaves points here
early in the season.

## Step 3 — The "slow station" conversation (10 min)

From your watch notes: which station took the longest? Talk through a faster
approach:
- **Powders slow** → batch the tests (all solubility, then all iodine, then all
  acid); use a dichotomous key instead of running every test on every cup.
- **Physical evidence slow** → these are mostly recall + short calculation; if a
  kid is stuck, flag it and move on, come back.
- **Analysis rushed** → start it earlier. The moment the IDs are done, one
  partner starts writing while the other double-checks IDs.

Agree on **who does what** next time — a written station split for the pair.

## Step 4 — Update the note sheets (10 min)

Every "didn't know it" miss becomes a line on the competition note sheet. By
Practice Test 3 the note sheets should be dense and personal — built from real
mistakes, not copied from the Knowledge Document.

## Tracking across the three tests

Keep a simple sheet:

| | PT 1 | PT 2 | PT 3 |
|---|---|---|---|
| Score | | | |
| "Didn't know it" misses | | | |
| "Ran out of time" misses | | | |
| "Reading error" misses | | | |
| Slowest station | | | |
| Analysis section % | | | |

The number that should climb most between PT 1 and PT 3 is the analysis
percentage — it's the most coachable, and it's a quarter of the test.
