# How to Run a Practice Test

Three of the season's meetings are full practice tests (after Session 6, after
Session 10, and right before competition). This is how to set one up and run it.

## 1. Pick a test

Use a real past invitational Division B Crime Busters exam that your team has
**not** seen. These are **not** in this repo (they're copyrighted), but the
hosting schools and test-exchange sites post them freely. Search for recent
invitationals — Oak Valley, Carmel Valley, Pembroke Hill, MIT, Princeton, and the
"SSSS" summer study-session series all publish Div B Crime Busters tests with
answer keys.

- **Practice Test 1:** an easier / older one is fine — the point is the routine.
- **Practice Test 2:** something closer to full difficulty.
- **Practice Test 3:** save a strong, recent one for this. Full competition
  conditions.

Print the test, the answer sheet, and the key (key stays with the coach).

## 2. Assemble the physical samples

The written test lists powders, liquids, metals, plastics, hairs, fibers, and
often soil and blood. You provide the physical unknowns. Three ways to do it:

| Sample type | How to provide it |
|---|---|
| **Powders** | Straight from the home-lab kit stock — baking soda, cornstarch, salt, both sugars, Epsom salt, cream of tartar, citric acid, chalk, sand, plus baking powder, gelatin, MSG, sodium acetate (hot-pack beads), washing soda. Label with numbers only. |
| **Liquids** | Water, white vinegar, lemon juice, isopropyl alcohol, hydrogen peroxide, salt water, sugar water, dilute ammonia (well-ventilated). Numbered dropper bottles. |
| **Metals** | Your labeled known set (Mg, Al, Fe, Zn, Sn, Cu — or the subset you have), re-numbered. |
| **Plastics** | Cut pieces from known items (soda bottle, milk jug, grocery bag, yogurt tub, CD case, acrylic offcut, PVC pipe). Or, if the test provides a density/burn table, you don't need physical samples for those. |
| **Hair / fiber** | Prepared slides or the printed micrograph packet. Fiber burn results: provide as a **description card** (real tests do this). |
| **Soil** | 2–3 jars of soil with a stated %sand/silt/clay on a card, or actual soil for a jar test. |
| **Blood** | The simulated typing kit from Session 10, or a printed agglutination grid. |
| **Anything you can't source** | A **description card**: "Plastic RP2 sinks in water, sinks in isopropyl, floats in saturated salt water." Real tests use these constantly. |

Match the sample numbers/letters to the test's answer sheet.

## 3. Set up the room

- One long table or two pushed together = the "station." Lay out the numbered
  samples with the shared tools (spot plates, droppers, iodine, vinegar or dilute
  HCl **with the coach supervising**, water, pH paper, magnet, hand lens,
  density-ladder liquids, chromatography strips + cups).
- Goggles and aprons required — no goggles, no start, just like competition.
- Each kid has their note sheet and a calculator.
- Waste cup and paper towels within reach. A trash bag for cleanup.

## 4. Run the clock

- **50 minutes**, timed, announced at the start. Call out the halfway point and
  the last 10 minutes.
- **Let them struggle.** Don't coach during the test. Just watch and take notes
  (see below).
- **Cleanup counts.** In the last 3–5 minutes they must clean the station —
  rinse everything, wipe surfaces, bag trash, return tools. A station not clean
  when you call time is a 10-point penalty, same as competition. Enforce it.

## 5. What to watch for while they work

Jot notes on:
- **Division of labor** — are the two of them splitting stations, or both hovering
  over the same cup? A good pair has one on powders/liquids while the other does
  physical evidence, then they trade.
- **Time sinks** — which station eats the most minutes? Usually powders (not
  batching tests) or the analysis writeup (started too late).
- **Skipped points** — blank formula columns, no "reason" next to an
  implication, the analysis section left half-done.
- **Test-reading errors** — answering the wrong sub-question, missing a "show
  your work," misreading a provided density table.
- **Safety / procedure** — goggles off, tasting, nose to a sample, sloppy with
  the acid.

Bring those notes to the answer review (next doc) and to the following weeks'
sessions.

## 6. After

Score it together using `Answer_Review_Guide.md`. File the test — you may reuse a
different section of it later, but don't re-run the same whole test.
