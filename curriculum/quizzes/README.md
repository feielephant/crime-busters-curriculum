# Quizzes

One short standalone quiz per teaching session (Quiz_01 … Quiz_12), for handing a
kid a review a week or two after a topic was taught, or as a warm-up at the start
of the next practice.

Each quiz is drawn from its session's own checkpoints, activities, and wrap-up —
**no new material** — reformatted for solo use, with an answer key at the bottom.
Length is deliberately short (10–20 minutes). These are review checks, not
test-difficulty practice; for that, use the homework and the practice tests.
