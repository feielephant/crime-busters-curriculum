# Quizzes

One short standalone quiz per teaching session (Quiz_02 … Quiz_12 — **no
Quiz_01**, since Session 1 is pure orientation with no testable science
content), for handing a kid a review a week or two after a topic was taught,
or as a warm-up at the start of the next practice.

**Quiz_02 is a merge** (former Quiz 2 + Quiz 3), matching Session 2's merge
into "Powders 101." Quiz_03 covers what used to be Session 1's content
("What the Judges Actually Score"), now taught in Session 3 — nothing else
renumbered.

Each quiz is drawn from its session's own checkpoints, activities, and wrap-up —
**no new material** — reformatted for solo use, with an answer key at the bottom.
Length is deliberately short (10–20 minutes, 20–25 for the merged Quiz 2). These
are review checks, not test-difficulty practice; for that, use the homework and
the practice tests.
