# Session 10: Blood
### Crime Busters Coach Script — [~90 min, dense — do not add to it]

## Before You Start

- **Learning goals:** Each kid can (1) read an agglutination grid (anti-A / anti-B
  / anti-D) and name the ABO/Rh type, (2) name the universal donor and recipient
  and list the ABO/Rh types from most to least common, (3) work a simple
  blood-type genetics cross and say what a child can and can't be, (4) explain
  what happens to blood chemically when it's exposed to air, and (5) name the
  common presumptive blood tests and what they show.
- **Year 1 recap:** none — blood was not taught last year. Budget accordingly.
- **Materials:**
  - Knowledge Document Chapter 13. Read closely.
  - **Simulated blood typing kit** — either a commercial one, or DIY: small
    bottles of colored water labeled "Blood A / B / AB / O / crime scene /
    Suspect 1–4" and "anti-A / anti-B / anti-D," with a rule sheet for which
    combos "agglutinate" (see prep). Well plates or spot plates, toothpicks.
  - Printed **Agglutination Grid worksheet**, **Punnett worksheet**,
    **Bloodstain Age cards** (below).
  - Optional demo: a fresh drop of blood (a volunteer's fingertip with a sterile
    lancet — coach only, or skip) or beet juice, left to dry over the session so
    kids see the color change; a bit of raw liver + hydrogen peroxide (the
    catalase foam, recap from Session 5).
  - Whiteboard.
- **Prep:** build or set up the typing kit and write the agglutination rules;
  design the crime-scene + 4-suspect blood set so exactly one suspect matches;
  print worksheets; start the "drying blood/beet juice" spot at the very start of
  class.
- **Vocabulary:** antigen · antibody · agglutination · ABO system · Rh factor
  (D antigen) · universal donor / recipient · allele · codominant · hemoglobin ·
  oxidation · clotting · presumptive test · Kastle-Meyer · luminol.

> **If you only have 60 minutes:** Cut the genetics/Punnett segment (0:52–1:07)
> to a 5-minute "here's the one rule (two O parents → only O kids; AB parent →
> never an O kid)" and move the rest to Homework 10. Keep the agglutination-grid
> lab and the blood-chemistry teaching.

## Segment-by-Segment Script

### 0:00–0:06 (6 min) — Hook

---

### 0:06–0:26 (20 min) — Direct Teaching: ABO / Rh Typing

- **COACH SCRIPT:**
  "Red blood cells carry markers on their surface called **antigens** — type A
  has the A antigen, type B has B, type AB has both, type O has neither. And your
  plasma carries **antibodies** against whatever you *don't* have — type A person
  has anti-B antibodies, type B has anti-A, type O has both, type AB has neither.

  When an antibody meets its matching antigen, the cells **clump together** —
  that's **agglutination**, and that clumping is how a blood-typing test is read.

  | Type | Antigens | Antibodies in plasma |
  |---|---|---|
  | A | A | anti-B |
  | B | B | anti-A |
  | AB | A and B | none — **universal recipient** |
  | O | none | anti-A and anti-B — **universal donor** |

  **Rh factor** is a separate antigen called **D**. Have it → you're Rh
  **positive**. Don't → Rh **negative**. So a full type is like **A+** or **O−**.

  - **Universal donor of red cells: O negative** (no A, no B, no D — nothing for
    anyone's antibodies to attack).
  - **Universal recipient: AB positive** (no antibodies — accepts anything).

  **Frequencies, most common to rarest — memorize this order:**
  **O+ > A+ > B+ > O− > A− > AB+ > B− > AB−.**"

- **[ACTIVITY: Read the Grid]**
  Put this table up and have kids fill the "type" column:

  | Anti-A | Anti-B | Anti-D | Type? |
  |---|---|---|---|
  | clump | — | clump | ? |
  | — | clump | — | ? |
  | clump | clump | clump | ? |
  | — | — | clump | ? |
  | — | — | — | ? |

  *(Answers: A+, B−, AB+, O+, O−.)*

  The rule: clump with anti-A → **has A**; clump with anti-B → **has B**; clump
  with anti-D → **Rh positive**. Both A and B → **AB**. Neither → **O**.

- **[CHECKPOINT:]** "Blood clumps with anti-B and anti-D only. Type?" (B+)
  "Universal donor?" (O−) "Most common type?" (O+)

---

### 0:26–0:52 (26 min) — Main Activity: Simulated Blood Typing

- **[ACTIVITY: Type the Crime Scene & Suspects]**
  Each pair gets the simulated kit: a "crime-scene" blood sample and 4 "suspect"
  samples, plus "anti-A / anti-B / anti-D." Using a well plate, they mix a drop of
  each blood with each antiserum, watch for "agglutination" (per your kit's
  rules), and fill the **Agglutination Grid worksheet**:
  - each sample's ABO/Rh type,
  - which suspect's type matches the crime scene,
  - a note: does matching blood type *prove* that suspect was there? (No — blood
    type is **class evidence**; it narrows, it doesn't identify. DNA would
    identify.)

  If your kit allows, include a twist: the crime-scene blood does **not** match
  the victim, suggesting the attacker was cut too — a great analysis point.

- **[CHECKPOINT:]** "Crime-scene blood is A+. Suspects are O+, A+, B−, AB+. Who's
  implicated, and is it proof?" (the A+ suspect is implicated; it is *not* proof —
  ~30% of people are A+; it's class evidence that narrows the field)

---

### 0:52–1:07 (15 min) — Direct Teaching: Blood-Type Genetics

- **COACH SCRIPT:**
  "You get one ABO allele from each parent. **A and B are codominant** — if you
  get both, you're AB. **O is recessive** — you're only type O if you got O from
  *both* parents.

  | Genotype | Blood type |
  |---|---|
  | AA or AO | A |
  | BB or BO | B |
  | AB | AB |
  | OO | O |

  So a type-A parent might secretly carry an O (genotype AO). That's why the
  cross questions are tricky.

  **The rules to lock in:**
  - **Two type-O parents → only type-O children.** (Neither has an A or B to
    give.)
  - **A type-AB parent → never a type-O child.** (AB always passes an A or a B.)
  - A type-A × type-B cross → the child could be **A, B, AB, or O** (if both
    parents carry an O). So 'which type can this child NOT be' → *none of the
    above; all are possible.*"

- **[ACTIVITY: Punnett Practice]**
  Kids fill 2×2 Punnett squares on the worksheet:
  - AO × BO → offspring types? (AB, A, B, O — all four possible)
  - OO × AO → ? (A, O)
  - AB × OO → ? (A, B — never O, never AB)

- **[CHECKPOINT:]** "Mom is type O, dad is type AB. Can they have a type-O child?"
  (No — dad always passes A or B) "Can they have a type-AB child?" (No — mom only
  has O to give; child is A or B)

---

### 1:07–1:20 (13 min) — Direct Teaching: Blood Chemistry & Presumptive Tests

- **COACH SCRIPT:**
  "**Hemoglobin** is the iron-containing protein in red cells that carries
  oxygen. Oxygen-rich blood (arteries, fresh air exposure) is **bright red**;
  oxygen-poor blood (veins) is **dark red**.

  **What happens when blood is exposed to air** — a 3-point question:
  1. Oxygen **binds the hemoglobin** and the blood turns **brighter red**.
  2. Within minutes, platelets activate and the blood **clots** (gels, then
     dries).
  3. Over hours the hemoglobin **oxidizes** — to methemoglobin, then brown
     hemichrome — so a dried stain goes **red → reddish-brown → dark brown**.
     (It also loses CO₂, nudging the pH up.)
  You can roughly estimate how **old** a bloodstain is from that color
  progression.

  **Presumptive tests** — you won't have the reagents, but they're short-answer:
  - **Kastle-Meyer** — phenolphthalein + hydrogen peroxide → turns **bright
    pink** if blood is present.
  - **Luminol** — sprayed in the dark, **glows blue** where there's blood, even
    if it was cleaned up.
  - **Precipitin test** — confirms the blood is **human**.
  Remember: **cyanoacrylate (superglue) fuming** and **Ardrox** are
  **fingerprint** developers, *not* blood tests — that's a trick question."

- **[ACTIVITY: Bloodstain Age Sort]**
  Kids order the Bloodstain Age cards (bright red → brown flaky) from freshest to
  oldest and label the chemistry at each step.

- **[CHECKPOINT:]** Check the drying spot from the start of class — has it
  darkened? "Why?" (hemoglobin oxidizing) "Kastle-Meyer turns pink — what does
  that tell you? Is it proof of blood?" (presumptive positive for blood — not
  confirmatory)

## Punnett Worksheet (print for kids)

Fill each square; list the possible child blood types.

1. AO × BO → __________________
2. OO × AO → __________________
3. AB × OO → __________________
4. AO × AO → __________________ *(A or O — AA, AO, AO, OO)*

## Bloodstain Age Cards (print & cut — order freshest → oldest)

- "Bright red, wet, spreads" — freshly shed, oxygen just bound to hemoglobin
- "Dark red, gel-like" — clotting; platelets activated
- "Reddish-brown, dry, shiny" — hemoglobin beginning to oxidize
- "Dark brown, matte, cracking" — oxidized to hemichrome
- "Brown-black, flaking off the surface" — old, fully oxidized and dehydrated

## Coach Notes & Common Kid Mistakes

- **Reversing antigen and antibody.** Type A has the A *antigen* on the cells and
  anti-*B* antibody in the plasma. Drill the table.
- **Reversing universal donor and recipient.** **O− gives** to everyone (nothing
  to react against); **AB+ receives** from everyone (no antibodies). Mnemonic:
  "O = zero antigens = safe to give."
- **Thinking a blood-type match is proof.** It's class evidence — ~1 in 3 people
  are O+. It narrows; it doesn't identify. DNA identifies.
- **Forgetting a type-A parent can carry O.** That's why A×B can produce an O
  child. The genotype (AO) hides behind the phenotype (A).
- **Saying luminol/Kastle-Meyer "confirms" blood.** Presumptive only. And
  **superglue fuming is for fingerprints**, not blood — the classic trap.
- **Missing the "crime-scene blood ≠ victim's blood" clue.** If the scene blood
  doesn't match the victim, the attacker may have been injured — a strong
  analysis point.
